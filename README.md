# keiba_prediction

> **このリポジトリについて（コードだけのコピー）**
>
> 元のリポジトリから、**成績データ（`data/`）、出馬表とオッズ（`cards/`）、学習済みモデル（`models/`）を除いた**、コードとドキュメントだけのコピーです。JRAの成績表（PDF）から作ったデータは、JRAの「ご利用に際して」（掲載内容を、私的使用・引用の範囲を超えて二次利用する場合は許諾が必要）に配慮して、含めていません。
> このままでは、`src/train.py`、Streamlitの画面、`scripts/predict_day.py` は、データがないので動きません。**動かすには、ご自身で、JRA公式サイトの [年度別全成績（PDF）](https://www.jra.go.jp/datafile/seiseki/report/2024.html)（年の部分を変えて、2024・2025・2026）を取得し、次の手順でデータを作ります**（個人の利用の範囲で。取得は、1ファイルずつ間隔を空けて）。
>
> 1. PDFを、`<年>/<競馬場>/<開催回>/` に置く（例：`2026/kyoto/1/2026-1kyoto1.pdf`）。
> 2. `scripts/extract_pdf.py` で、CSVに変換する（使い方は、下の「PDFからCSVを作り直す」）。年ごとに `data/all_<年>.csv` にする。
> 3. `scripts/review_csv.py` で、PDFと照合する。
> 4. （任意）`scripts/fetch_weather.py` で、気象庁の気象データを取得する。
> 5. `uv run python scripts/train_model.py` で、モデルを作る。
>
> 評価の数字・結論は、元のデータで作ったものです。

JRA の成績PDFを1頭1行のCSVに変換し、その馬が **3着以内に入るか** を予測する機械学習モデルです。
データは次の3年分、全10場で計9,663レース・132,545頭です。

| 年 | 期間 | 競馬場 | レース数 |
|---|---|---|---|
| 2024年 | 1月6日〜12月28日 | 全10場（阪神は1・2回のみ） | 3,454 |
| 2025年 | 1月5日〜12月28日 | 全10場 | 3,455 |
| 2026年 | 1月4日〜10月18日 | 全10場 | 2,754 |

## 結論と限界

> **評価の数字について**: この節以降の評価（2026年3〜9月の1,956レース・26,597頭）は、2026年9月27日までのデータで作りました。その後、8月29〜30日分（新潟3回・中京3回、手元に抜けていた4日分）と10月3〜18日分を取り込んだので、評価するレースは2,004レース・27,251頭に増えています。再計算した主な指標は、ほぼ同じです（3着内のAUC：市場 0.8205、オッズなし 0.7862、オッズあり 0.8206。LogLoss：0.4054、0.4343、0.4055）。表の詳しい数字（信頼区間、回収率など）は、1,956レースの時点の値のままです。

**公開されている成績情報（着順・タイム・オッズ・騎手・調教師・馬体重・通過順位・払戻・気象）の範囲では、オッズ（市場）を超える予測は作れませんでした。** オッズを使わないモデルは、市場にかなり近い順位づけまで再現できましたが、市場の上に乗る情報は、検出できませんでした。

評価は、2026年3〜9月の1,956レースを、各月それより前のデータだけで学習して予測する方法です（リークなし。区間は、レースを復元抽出する95%区間）。

| 問い | 結果 |
|---|---|
| オッズを使わずに、どこまで市場に近づけたか | レース内AUC 0.7635（市場は0.8005）。全体のAUCは0.786（市場は0.821） |
| オッズありのモデルは、市場を超えたか（3着以内） | **超えていない**。LogLossの差は+0.0001（区間−0.0001〜+0.0005）、レース内AUCの差は+0.0004（区間−0.0002〜+0.0010） |
| 勝ち馬の予測は、市場を超えたか | 勝ち馬の対数尤度が+0.0027/レース（区間+0.0008〜+0.0048）と、統計的には市場より良いが、差はごくわずか。係数はマイナスで、「市場が見落とした強い馬を見つける」形ではない |
| 割安な馬（期待値が1を超える馬）は見つかったか | 単勝：1,956レースの中に1頭だけ。複勝：期待値1.0以上の1,220頭の回収率は86.6%（区間77.3〜97.1%）で、100%を超えない |
| 馬券で利益は出るか | **出ない**。回収率は、1番人気・モデルの1位とも、単勝で約78%、複勝で約84〜85% |
| データを増やすと、どこまで伸びるか | 京都のみ0.712 → 全場2026年0.771 → 2025年を追加 0.784 → 2024年を追加 0.786。過去出走がある馬の割合が91.4%に達し、ほぼ頭打ち |
| 特徴量を増やすと、どこまで伸びるか | コースの形・相性・脚質・気象・道悪適性の5グループは、どれもAUCの差が±0.0001以内で、寄与ほぼゼロ |

### 「オッズの約9割に届いた」と言えるか

言えますが、但し書きが必要です。
- 基準の取り方で割合が変わります（生の比は95%、偶然の0.5を基準にすると約88%）。
- LogLossで見ると届いていません。勝ち馬の予測では、オッズなしモデルは市場より1レースあたり0.21悪いです。
- 厳密な「オッズなし」ではありません。特徴量に前走の市場評価（前走のオッズ）が入っています。「このレースのオッズなし」が正確です。

### 言い切れること、言い切れないこと

**言い切れる**: この特徴量・この結合方法・この7か月では、オッズありモデルの3着以内の上乗せは、ゼロと区別できません。

**言い切れない**:
- 評価が1,956レース・7か月だけで、季節や馬場の偏りを確かめられていません。
- 回収率の区間が±10〜15ポイントあり、控除率（約20%）を覆す優位があっても、検出できません。
- 血統・調教・パドックの情報が入っていません。
- **最終オッズを使っています**。馬券を買う時点では使えないので、実際の運用では、ここに書いた結果より悪くなる方向に偏っています。

### 結果の読み方（推測を含む）

- 勝ち馬の予測でモデルの係数がマイナスになるのは、モデルが見ている過去成績が一般のファンにも見える情報で、成績が目立つ馬ほど買われすぎるため、その分を割り引く補正として効いているのかもしれません。この場合、+0.0027は「モデルの能力」ではなく「市場の偏りの補正」です。
- 複勝の期待値が予想（110%）を下回る（実際は87%）のは、期待値が1を超える馬を選ぶ時点で、見積もりが上振れした馬が集まるためです（選択バイアス）。モデルの期待値と市場だけの期待値がほぼ同じなので、主な原因は予想払戻の見積もり誤差とみています。
- 「市場より高く評価した馬の複勝率が約0.5ポイント高い」という差は、標準誤差（約1.4ポイント）の範囲内で、根拠としては弱いです。

## 予想の画面（Streamlit）

学習済みモデルを動かして、**これからのレースを予想**したり、過去のレースで確かめたりできる画面です。

```bash
uv run python scripts/train_model.py     # 最終モデルとバックテストを作る（約6分。models/ に保存）
uv run streamlit run app/streamlit_app.py
```

| タブ | 内容 |
|---|---|
| 予想する | **取得元を選び、開催とレースを選んで、「予想する」を押すだけ**。取得元は、今週の開催（JRA公式サイトの「出馬表」から自動で取り込む。数秒）／保存した出馬表（`cards/*.json`）／過去のレース（履歴から。練習用）／手で入力する（CSVのアップロードも可）。馬場と天候だけ、当日の発表に合わせて選ぶ（初期値は良・晴）。馬ごとに **① 能力勝率**（オッズを見る前に決める）と **② オッズを使った期待値・市場との比較** を出す。「最新のオッズに更新」で、オッズを取り直せる |
| 過去のレースで確かめる | 2026年3〜9月のレースを、各月より前のデータだけで学習したモデルで予測した結果を、実際の着順と並べる |
| モデルの成績 | 市場（オッズ）との比較（AUC・LogLoss）と、各レースの1位を買った場合の回収率 |
| 予想の前提 | [docs/principles.md](docs/principles.md)（馬選びの前提15項目と、今のモデルでの対応状況） |

出馬表は、JRA公式サイトの「出馬表」（馬番確定後。前日の午前10時ごろから）から、画面が自動で取り込みます。取り込みは、1回の操作で2〜3アクセス（1秒間隔）にとどめ、個人の利用の範囲で使ってください（JRAの「ご利用に際して」: 掲載内容を、私的使用・引用の範囲を超えて二次利用する場合は、許諾が必要）。馬体重は、発表後（当日の朝）に取り込めます。1日分の全レースをまとめて予想する場合は、出馬表をJSONにして（形は `scripts/predict_day.py` の説明を参照。`cards/` は、このコピーには含まれません）、次のコマンドで、Markdownの予想表を作れます。

```bash
uv run python scripts/predict_day.py cards/2026-10-25_kyoto.json    # cards/2026-10-25_kyoto_predictions.md ができる（12レースで約3分）
```

JRA公式サイトの「出馬表」→ 開催を選ぶ → 「全てのレースを表示」のページに、その日の全レースの出馬表（枠・馬番・性齢・斤量・騎手・調教師・単勝オッズ、馬体重は発表後）が載っていて、`src/jra_card.py` はこのページを読み取ります。予想には、出馬表の日付より前の成績の履歴だけを使います（履歴は、成績CSVの最後の日まで）。

**画面を使う前に知っておくこと**
- このモデルは、公開されている成績情報の範囲では、オッズ（市場）を超えていません（上の「結論と限界」）。馬券で利益が出る保証はありません。
- 「能力勝率 × オッズ」の期待値は、**買い目の根拠にしないでください**。オッズを見ずに決めた勝率は、人気薄を市場より高く見積もるため、検証（2026年3〜9月）では、期待値が1を超えた馬（全体の53%）の実際の単勝回収率は70%で、期待値の高さと回収率に関係がありませんでした（詳しくは [docs/principles.md](docs/principles.md) の最後）。
- 予想には、1回あたり約12〜20秒かかります（履歴から、馬・騎手・調教師に関係する行だけを使って特徴量を作ります）。

## 使い方

### 学習と評価

```bash
uv run python src/train.py              # オッズ + 馬・騎手・調教師の情報で予測
uv run python src/train.py --no-odds    # オッズを使わず、馬・騎手・調教師の情報だけで予測
```

### PDFからCSVを作り直す（任意）

JRA公式サイトの「レース成績」PDF（`2026-1kyoto1.pdf` など）を手元に置いて実行します。PDFはリポジトリに含めていません。
複数の競馬場・開催のPDFをまとめて渡せば、1つのCSVになります。CSVは年ごとに分けます。`race_id` は同じ年の中では全場で重複しませんが、年をまたぐと重複するので、`train.py` が読み込み時に年を付けて区別します。

```bash
uv run python scripts/extract_pdf.py path/to/1/*.pdf path/to/2/*.pdf path/to/3/*.pdf -o data/all_2026.csv
uv run python scripts/review_csv.py data/all_2026.csv path/to/1/*.pdf path/to/2/*.pdf path/to/3/*.pdf
```

`review_csv.py` は、レースごとの頭数と勝ち馬の単勝払戻金をPDFの値と突き合わせ、ERRORがあれば終了コード1を返します。

CSVには成績のほか、発走時刻（`start_time`）と、PDFの「コーナー通過順位」から読み取った各コーナーの通過順（`corner1`〜`corner4`、`corner4` が最終コーナー）が入ります。
3・4コーナーしかないコースは `corner3`・`corner4` だけ、コーナーのない新潟の直線1000mは空欄です。2周するコースは後半の周回の値です。

払戻欄から、`win_payout`（勝ち馬の単勝払戻、100円あたりの円）と `place_payout`（複勝の払戻、3着以内に入った馬のみ。入らなかった馬は0）も読み取ります。複勝の馬番は丸数字の図形で書かれていて文字として読めないため、払戻は着順（1着、2着、3着）の並びに対応させています（全レースで検証済みで、並びが逆転して見える馬は27,897頭中17頭）。1着同着のレースなど、払戻の表の文字が重なって読めないレース（14レース・211頭）は空欄です。

2024年の成績PDFは、JRA公式サイトの [年度別全成績（PDF）](https://www.jra.go.jp/datafile/seiseki/report/2024.html) から取得しました。阪神は公式サイトに1回・2回（16日分）しか公開されておらず、3回以降は含まれません。

### 気象データを取得する（任意）

```bash
uv run python scripts/fetch_weather.py
```

気象庁「過去の気象データ検索」から、`data/all_*.csv` の開催日について、各競馬場の最寄りの観測所の1時間ごとの値（気温・湿度・風速・降水量）を取得し、年ごとに `data/weather_<年>.csv` に保存します。
取得したページは `data/.jma_cache/` に保存し（Git管理外）、2回目以降は気象庁にアクセスしません。

| 競馬場 | 観測所 | 競馬場 | 観測所 |
|---|---|---|---|
| 札幌 | 札幌 | 中山 | 船橋（アメダス） |
| 函館 | 函館 | 中京 | 名古屋 |
| 福島 | 福島 | 京都 | 京都 |
| 新潟 | 新潟 | 阪神 | 大阪 |
| 東京 | 府中（アメダス） | 小倉 | 八幡（アメダス。小倉は湿度などを観測していないため） |

2024年の府中・船橋（東京・中山の開催日）は、湿度を観測していない期間があり（東京38日、中山32日）、その日の湿度は空欄です。モデルは空欄をそのまま扱い、気象は精度に効いていないため、補完はしていません。

## モデル

コードの詳しい解説は [docs/modeling.md](docs/modeling.md) を参照してください。

- **目的変数**: 3着以内なら1（`finish <= 3`）。競走中止は0
- **構成**: 2段構成
  1. **能力モデル**: オッズを使わない特徴量から3着内確率を予測する勾配ブースティング（scikit-learn の `HistGradientBoostingClassifier`）
  2. **組み合わせ（オッズありのときのみ）**: 市場の勝率（単勝オッズから計算）・能力モデルの予測・頭数をロジスティック回帰で組み合わせる
- **後処理**: レース内で確率の合計が3（3着以内の頭数）になるようにそろえる
- **評価**: ウォークフォワード。2026年3〜9月の各月について、その月より前のデータ（2025年1月〜）だけで学習して予測（計1,956レース）

### 特徴量（能力モデル、77個）

| 種類 | 特徴量 |
|---|---|
| レース条件 | 競馬場、芝/ダート/障害、回り（右/左/直線）、内回り/外回り、馬場状態、クラス（とその格）、距離、ハンデ戦か、天候、頭数 |
| 気象 | 発走時刻の気温・湿度・風速・降水量、その日の発走までの降水量（気象庁） |
| 馬 | 枠番、馬番、性別、年齢、斤量、減量騎手の減量幅、ブリンカー、馬体重、馬体重増減 |
| 馬の過去成績 | 出走数、前走・平均・最高の着順率、過去の3着内率、前走・平均の勝ち馬とのタイム差、前走・平均の市場評価、前走からの間隔 |
| 前走からの変化 | 昇級・降級、乗り替わり、斤量の増減、距離の増減、同じ芝/ダートか |
| コース適性 | 同じ芝/ダートでの平均着順率、同じ競馬場での出走数 |
| 脚質 | 前走・過去平均の序盤の位置（0 = 先頭）、逃げた割合、過去平均の最終コーナーの位置、直線で抜いた頭数の平均、このレースの先行タイプの頭数 |
| 道悪適性 | 道悪（稍重・重・不良）と良馬場それぞれでの過去平均着順率とその差、道悪の出走数、道悪でのタイム差の広がり、今日と同じ条件（芝/ダート × 道悪/良）での過去平均着順率 |
| 人 | 騎手・調教師のそれまでの騎乗数と3着内率、騎手の芝/ダート/障害別の3着内率（全体平均で平滑化） |
| 相性 | 馬×騎手（コンビ）、騎手×調教師のそれまでの回数と3着内率 |
| レース内の相対値 | 騎手・調教師の3着内率、馬の平均着順率・最高着順率・3着内率・平均タイム差・平均市場評価・序盤の位置、斤量、馬体重、年齢を、同じレースの馬の中でzスコアにしたもの |

過去成績・騎手・調教師の成績は、**そのレースより前の日付のデータだけ**から計算しており、未来の結果が混ざらないようにしています。
`finish`・`time`・`time_sec`・`win` はレース結果なので、特徴量には使っていません。

### 読み方と限界

- **オッズなしモデルが改善**: 2025年のデータを学習に加えると、AUCは 0.771→0.783、LogLossは 0.444→0.436 に上がりました。評価する馬のうち過去の出走がデータにある割合が、84%から91%に増えたことが主因です（2024年を加えても91.4%で、ほぼ上限です）。中山・中京を加えた全10場では 0.784、2024年を加えると 0.786 と、伸びは小さくなっています。予測1位の複勝率も 55.7%→58.1% に上がり、1番人気（65.8%）との差が縮まりました。
- **新しい特徴量は2025年を加えても効果なし**: コースの形・相性・脚質・気象・道悪適性は、1グループずつ外して比べても、どれもAUCの差が±0.0001以内でした（95%区間が0をまたぐ。全10場で確認）。上がったのは特徴量の効果ではなく、データが増えた効果です。
- 道悪のレースに出る馬のうち、道悪と良馬場の両方を走った経験がある馬は、2026年だけのときの35%から66%に増えましたが（経験回数の中央値は2回）、それでも道悪適性は効きませんでした。
- **オッズありは変わらず**: オッズありのモデルは、オッズだけのロジスティック回帰と同じ精度（AUC 0.821）のままです。2段目の係数は市場の勝率0.97に対して能力モデル0.06で、能力モデルの上乗せは小さいです。LogLossはオッズだけのモデル（0.405）の方がわずかに良く、能力モデルの上乗せは見られません。
- 単勝回収率は、モデル・1番人気のどれも70〜79%で、100%を下回っています。**このモデルで馬券の利益は出ません**。

## 市場（オッズ）と比べた評価（`src/evaluate.py`）

AUCやLogLossが高くても、それがオッズから分かる範囲なら、馬券では役に立ちません。そこで、**オッズと比べてどれだけ良いか**を、レース単位のブートストラップによる95%区間つきで測ります。

```bash
uv run python src/evaluate.py
```

評価は、これまでと同じ2026年3〜9月の1,956レースです。

| 評価 | 結果 | 95%区間 |
|---|---|---|
| **勝ち馬の予測**: 市場の勝率に「3着以内を目的にした能力モデル」を足した改善（勝ち馬の対数尤度、1レースあたり） | +0.0027 | +0.0008〜+0.0048 |
| **勝ち馬の予測**: 市場の勝率に「勝ちを目的にした能力モデル」を足した改善 | +0.0021 | +0.0004〜+0.0038 |
| **勝ち馬の予測**: 市場の勝率に両方の能力モデルを足した改善 | +0.0027 | +0.0008〜+0.0047 |
| 参考: 勝ちを目的にした能力モデル単独（オッズなし） − 市場 | −0.2117 | −0.2383〜−0.1856 |
| **3着以内**: オッズありモデル − 市場、LogLoss | +0.0001（悪化方向） | −0.0001〜+0.0005 |
| **3着以内**: オッズありモデル − 市場、レース内AUC | +0.0004 | −0.0002〜+0.0010 |
| 参考: オッズなしモデル − 市場、レース内AUC | −0.0370 | −0.0418〜−0.0321 |

- 勝ち馬の予測は、市場に能力モデルを足すと、統計的には0と区別できる改善（+0.0021〜+0.0027/レース）になりますが、大きさは勝ち馬の確率で約0.2〜0.3%の差にすぎません。係数は、どちらの能力モデルも **マイナス**（3着以内の目的：−0.07〜−0.11、勝ちの目的：−0.06〜−0.09）で、「市場が見落としている強い馬を見つける」形ではありません。
- **勝ちを目的にした能力モデルでも、改善は増えませんでした**（+0.0021、3着以内の目的の+0.0027より小さい）。両方を足しても+0.0027で、同じです。「3着以内の目的だから勝ち馬の予測に合わない」という仮説は、否定されました。マイナスの係数は、能力モデルが市場から離れて評価する部分（市場より高く評価した馬）が、むしろ勝ちにくい方向に出ていることを示します（解釈は推測。部分的に、オッズが見ている情報より劣る予測を、取り除く効果が出ているとみています）。
- 勝ちを目的にした能力モデルを単独（オッズなし）で使うと、勝ち馬の対数尤度は市場より0.21/レース悪く（95%区間 −0.24〜−0.19）、オッズの代わりにはなりません。
- 3着以内の予測は、市場との差は誤差の範囲です。
- **校正**: モデルの予測を市場の予測と比べると、94%の馬は±5%以内で、ほぼ同じ評価です。市場より高く評価した馬（比 1.05〜1.15、853頭）の複勝率は、モデルの予測どおり市場より約0.5ポイント高く、方向は合っていますが、差は小さいです。
- **期待値**（モデルの勝率 × オッズ）が1を超える馬は、1,956レースの中に1頭しかありませんでした。モデルは割安な馬を見つけていません。期待値0.85〜1.0の馬（770頭）の単勝回収率は92.4%（95%区間 73〜112%）で、誤差が大きく、100%を超えたとも言えません。
- レース内の順位で測ると、市場のAUCは0.8005、オッズなしモデルは0.7635です（レース全体をまとめた値は0.8206と0.7858）。

### 複勝（3着以内に入れば払戻）の評価

払戻欄から読み取った**実際の複勝払戻**で、複勝を買った場合の回収率を測ります（払戻を読めた1,954レース、100円あたり）。

| 戦略 | 賭け数 | 的中率 | 回収率 | 95%区間 |
|---|---|---|---|---|
| 全馬に賭ける（基準） | 26,565 | 21.8% | 72.3% | 69.7〜75.1% |
| 1番人気 | 1,954 | 65.4% | 84.9% | 82.0〜87.6% |
| 市場の予測1位（オッズ＋頭数） | 1,954 | 65.4% | 84.9% | 82.0〜87.6% |
| オッズなしモデルの1位 | 1,954 | 57.4% | 79.2% | 75.7〜82.6% |
| オッズありモデルの1位 | 1,954 | 65.0% | 84.2% | 81.4〜87.0% |

期待値は、「モデルの3着内確率 × 予想払戻」で作ります。予想払戻は、学習データで求めた「3着以内に入ったときの払戻」と単勝オッズの関係（対数どうしの直線）から出します。期待値が一定以上の馬を、すべて買った場合です。

| 期待値 | 賭け数 | 回収率 | 95%区間 |
|---|---|---|---|
| 0.8 以上 | 9,325 | 80.7% | 78.4〜83.2% |
| 0.9 以上 | 3,615 | 82.4% | 77.9〜87.1% |
| 1.0 以上 | 1,220 | 86.6% | 77.3〜97.1% |
| 1.1 以上 | 430 | 88.1% | 72.7〜104.8% |

- 複勝でも、**回収率が100%を安定して超える領域はありません**。期待値1.0以上の1,220頭は、予想では110%のところ、実際は86.6%（95%区間の上限97.1%）でした。1.1以上の430頭は区間が広く（72.7〜104.8%）、100%を超えるかどうかは分かりません。
- 1番人気の複勝は、的中率65.4%・回収率84.9%で、一番高い回収率でした。モデルの1位（84.2%）と同じで、上回れていません。
- モデルの期待値と、市場だけの期待値は、ほぼ同じ値（例：0.9〜1.0の区分で94.1%と93.9%）で、モデルは市場と同じ評価を出しています。
- 期待値の予想（110%）が実際（87%）を大きく上回るのは、期待値の高い馬は人気薄が多く、「人気薄の3着内確率」と「3着以内に入ったときの払戻」の両方を少し楽観的に見積もっている（選んだ馬の成績が、選んだ時点の見積もりより悪くなる）ためとみています（推測）。

## 今後の改善案

- 道悪適性を血統（父の道悪成績）から補う。PDFには勝ち馬の血統しか載っていないため、別のデータが必要
- 勝ち馬を目的にした能力モデルを作る（今の能力モデルは3着以内が目的なので、市場の勝率を補正する用途では、勝ちやすさを直接学習した方が合う可能性がある）
- 着差・馬主・生産者・外国産/地方の印など、変換スクリプトで未取得の列を追加する
- 過去年度の成績PDFを追加し、2歳時・前年の成績も使えるようにする
- 血統（父・母父）を加える
- 回収率を目的にする場合は、予測確率とオッズから期待値を計算して買い目を絞る
