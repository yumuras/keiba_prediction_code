# 馬選びの前提（予想で守ること）

予想をするときの前提です。モデルの出力を見るときも、新しい特徴量を考えるときも、この前提に合っているかを確認します。

## 前提

### 1. 結果の見方
1. 着順・着差・時計を、そのまま能力評価にしない。その結果になった理由まで回顧する。
2. 「負けて強し」「勝って恵まれ」を見分ける。不利な展開でも内容が良かった馬を評価し、楽な展開で勝った馬を過大評価しない。
3. 「負けて強し」だけで大幅加点しない。能力、相手関係、今回の条件と合わせて判断する。
4. レースの格だけで相手関係を決めない。対戦相手の実力や、その後の成績から、実際のレースレベルを判断する。
5. 古馬混合戦での実績も評価する。同世代限定戦との違いを考え、古馬混合2勝クラスなどで通用した内容を軽視しない。

### 2. 展開・条件
6. 前半・後半ラップと通過位置をセットで見る。ハイペースを先行したのか、スローで後方にいたのかなど、各馬の負担を読み取る。
7. 距離適性は出走実績だけで決めない。他の距離でも、ラップや追走の仕方から、今回の距離に対応できるかを考える。
8. スタート・折り合い・進路・距離ロスを確認する。**映像で確認できていない不利は断定しない。**
9. 馬場適性と当日の馬場を合わせる。重馬場で強かった内容を、良馬場でも同じように評価しない。
10. 馬場バイアスを考慮する。内外・前後の有利不利を見て、**前日の傾向は翌日に機械的に持ち越さない。**
11. 枠順は、脚質や周囲の馬と組み合わせて評価する。テンの速さ、先行争い、想定位置、通りそうな進路まで考える。
12. 今回も同じ強さを発揮できるかを考える。過去の好走条件が、今回の距離・馬場・枠・展開でも再現できるかを見る。

### 3. 比較と確率
13. 斤量・騎手も含めて全頭を比較する。特定の馬だけを詳しく見て、ほかを雑に扱わない。
14. 弱い馬にも一律で3〜8%を配らない。能力的に厳しい馬は、勝率3%未満も含めて差をつける。
15. **能力勝率にオッズや他人の評価を混ぜない。** まず独立して勝率を決め、固定した後にオッズを使って期待値を計算する。

### 4. 追加の視点（ある予想家の考え方）
16. 着順より「負けた理由」を重視する。不利な展開・物理的なロス（外回し、詰まり）の敗戦は、着順ほど能力負けではないと見る。
17. 展開・馬場のバイアス（スロー、前残り、内有利）が、特定の馬に極端に有利・不利でなかったかを見る。前残りで好走しただけの馬は割り引く。
18. 物理的なロス（外を回して好走）を高く評価する。内・前が有利な条件で、外を回して好走した馬は、能力が高い。
19. 「未知の要素が多い馬」（無敗の人気馬など）より、「実績ある実力馬」のオッズ妙味を取る。過剰人気を避ける。
20. 人気馬を無理に本命にしない。好走確率に対して、オッズが最も美味しい馬を狙う（オッズに見合わなければ、紐まで）。

## 2段構えの手順（15 に対応）

1. **能力勝率を決める**：オッズ・人気・過去のオッズ（市場評価）を使わない特徴量だけで、馬ごとの勝率を出します。この値は、オッズを見る前に固定します。
2. **オッズで期待値を計算する**：固定した勝率に、単勝オッズをかけます（期待値 ＝ 勝率 × オッズ）。1を超える馬が、割安の候補です。

「能力勝率」と「オッズありの確率」は、別のものとして扱います。オッズありの確率（市場を組み込んだ3着内確率）は、市場との比較や、参考としてだけ使います。

## 検証：15（能力勝率とオッズの期待値）を守るとどうなるか

能力勝率を、オッズ・過去のオッズ由来の特徴量（`prev_mkt_prob`、`mean_mkt_prob`、`mean_mkt_prob_z`）なしで決めて、固定してから、オッズをかけて期待値を計算しました（2026年3〜9月、1,956レース・26,597頭）。

| 項目 | 結果 |
|---|---|
| 勝ち馬の対数尤度（1レースあたり） | 独立 −2.1401／市場の情報あり −2.1336／**市場（オッズそのまま）−1.9248**。独立にしても、能力モデルの精度はほとんど落ちない（−0.0065）が、**市場には大きく及ばない**（−0.21） |
| 勝率の分布（14） | 3%未満が35%、3〜8%が33%。**一律には配っていない**（市場は3%未満が48%）。ただし最も弱い馬を少し高く見積もる偏りがあり、勝率を `p^1.076` に尖らせると直る（勝ち馬の対数尤度 −2.1401 → −2.1383） |
| 期待値 = 能力勝率 × オッズ が1を超えた馬 | 全体の**53%**（1レースあたり7.2頭）。その馬の実際の単勝回収率は**70%** |
| 期待値の区分と実際の回収率 | 〜0.5：86%、0.85〜1.0：67%、1.2〜1.5：56%、2.0以上：78%。**期待値の高さと回収率に関係は見られない** |

**読み方**: オッズを見ずに決めた勝率は、市場より「平らな」分布になり（人気薄を高く、人気馬を低く見積もる）、オッズをかけると、人気薄で期待値が大きく出すぎます。市場は、公開されている成績情報より多くのことを知っているので（検証で確認）、独立した勝率だけでは、割安な馬を見つけられません。

したがって、**15を守る（能力勝率を独立に決める）ことと、期待値で割安な馬を見つけることは、両立しません**。画面では、期待値を表示しますが、買い目の根拠にしないよう、警告を出しています。割安な馬を探すなら、市場の情報を組み込んだ確率（Benter型、README「市場（オッズ）と比べた評価」）で、市場との差を見る必要があります。

## 検証：4・5・6・11 を特徴量にしても精度は変わらなかった

PDFから取れる情報（内外の位置、年齢条件、ハロンタイム）と、前走の相手のその後の成績を、特徴量にして追加し、2026年3〜9月で比べました（3着内、基準は77個の特徴量）。

| 追加したもの | オッズなし AUC / LogLoss | オッズあり AUC / LogLoss |
|---|---|---|
| 基準 | 0.7860 / 0.4344 | 0.8206 / 0.4055 |
| 年齢条件・古馬混合戦の成績（6個） | 0.7859 / 0.4345 | 0.8206 / 0.4055 |
| ペース・展開（3個） | 0.7859 / 0.4345 | 0.8206 / 0.4055 |
| レースレベル（2個） | 0.7860 / 0.4344 | 0.8206 / 0.4055 |
| 内外の位置（3個） | 0.7861 / — | 0.8206 / — |
| 全部（11個） | 0.7857 / 0.4346 | 0.8206 / 0.4056 |

どれも、差は0.0003以下で、誤差の範囲です。これらの情報は、すでにある特徴量（枠・脚質・通過順位・着順・クラス）でほぼ説明できていて、PDFの範囲では、新しい情報にならないと考えられます。列は `add_features` で作られるので、後から試せます（`src/train.py` の `EXPERIMENTAL_FEATURES`）。

## 検証：追加の視点（16〜20）をデータで確かめる

2024〜2026年の全13万頭で、単勝の市場の勝率（オッズから）と実際の勝率を比べました。**市場の勝率と実際の勝率が一致していれば、その視点には、オッズ上の妙味が無い**、という意味です。

| 視点 | 条件 | 市場の勝率 | 実際の勝率 | 比 | 単勝回収率 |
|---|---|---|---|---|---|
| 全体 | 132,545頭 | 7.3% | 7.3% | 1.00 | 72.2% |
| 19 経験が浅い馬 | 初出走 / 1〜2走 / 3〜5走 / 6〜10走 / 11走以上 | 6.7 / 7.2 / 8.0 / 7.9 / 5.9% | 6.6 / 7.2 / 8.0 / 8.0 / 5.7% | 0.99 / 0.99 / 1.01 / 1.02 / 0.97 | 63 / 70 / 71 / 84 / 71% |
| 19 無敗馬 | 1,387頭 | 14.6% | 13.6% | **0.93**（−1.2σ） | 73.3% |
| 19 人気の無敗馬 | 市場勝率20%以上、366頭 | 33.3% | 27.6% | **0.83**（−2.4σ。2024年−2.0σ、2025年−1.5σ、2026年−0.3σ） | 65.4% |
| 20 人気馬 | 市場勝率20%以上、13,403頭 | 31.1% | 31.7% | 1.02 | 80.5% |
| 19 実績馬の前走の凡走 | 4走以上、3着内率45%以上、前走5割より下、2,274頭 | 9.0% | 8.9% | 0.99 | 76.9% |
| 18 外を回して好走 | 前走の4コーナーの位置が外寄りで、着順が上位3割、11,005頭 | 15.3% | 15.2% | 1.00 | 77.8% |

**読み方**
- 経験の浅い馬・実績馬の凡走・外を回して好走した馬は、**市場が、すでに適切に織り込んでいて**、オッズ上の妙味は見られませんでした（比がほぼ1）。
- 人気馬は、むしろ、市場の勝率の1.02倍と、わずかに過小評価でした（20「人気馬を無理に本命にしない」を支持するデータは無し）。
- **無敗馬は、弱い兆候**があります。3年とも、市場から期待される勝ち数より少なく勝ちました。ただし、全無敗馬では −1.2σ（偶然でもあり得る）で、人気の無敗馬の −2.4σ は、条件を絞って見つけたものなので、偶然の可能性があります。
- そこで、画面に「理論の補正（無敗馬を割引）」を選択肢として加えました。無敗馬の市場込みの勝率を、**0.93倍**（全無敗馬の比）して、合計1にそろえ直します（`UNBEATEN_FACTOR`）。人気馬の0.83倍までは割り引いていません（偶然の可能性が高いため）。
- 16・17（負けた理由、展開・馬場のバイアス）は、前提1・2・6・10と同じで、ペースと通過位置を使った特徴量は、すでに試して、精度が変わりませんでした（上の検証）。
